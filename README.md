# Sanjeet Singh – Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS and JavaScript, deployed on GitHub Pages.

**Live site:** https://sanjeet0427.github.io/portfolio-website/

## About

I'm a third-year B.Tech Computer Science Engineering student at Shri Ramswaroop Memorial University, Lucknow, specializing in Cloud Computing with AI. This site shows my education, skills, experience, projects and contact details.

## Sections

- About Me
- Education
- Skills
- Experience and certifications
- Projects
- Contact

## Features

- Responsive layout for phones, tablets and desktops
- Animated typing terminal intro in the hero section
- Light and dark theme toggle, saved between visits
- Skill filter tabs (Languages, Core concepts, Tools, Focus areas)
- Expandable project details
- Mobile navigation menu
- Contact form with validation that opens the visitor's email app
- Respects the reduced-motion setting and has visible keyboard focus

## Built with

- HTML5
- CSS3 (custom properties, flexbox, grid, media queries)
- JavaScript (vanilla, no libraries)
- Google Fonts: Bricolage Grotesque and DM Sans
- GitHub Pages for hosting

## Project structure

```
portfolio-website/
├── index.html   # page structure and content
├── style.css    # styling, themes and responsive layout
├── script.js    # menu, theme toggle, skill filter, form, terminal intro
└── README.md
```

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a web browser. No build step is needed.
